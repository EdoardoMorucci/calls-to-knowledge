+ FTS Virtual Table (Full Text Search)

SQLite richiede una virtual table separata per la ricerca full-text:

CREATE VIRTUAL TABLE transcripts_fts
  USING fts5(call_id, full_text, content=transcripts);

Popolata automaticamente via trigger INSERT/UPDATE su transcripts. Permette query tipo: WHERE transcripts_fts MATCH 'budget Q1'
