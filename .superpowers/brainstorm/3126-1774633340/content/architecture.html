Architettura — Calls to Knowledge

3 processi indipendenti che comunicano tra loro

🐍 Python Backend (FastAPI)

Porta: 8000

  • 🎙️ Audio Monitor (WASAPI) — rileva chiamate
  • ⏺️ Audio Recorder — cattura loopback
  • 📝 Transcription Service — OpenAI Whisper
  • 🤖 AI Processor — GPT-4o (summary, key points, next steps)
  • 🗄️ Storage — SQLite via SQLAlchemy
  • 🔌 REST API — chiamate, progetti, trascrizioni
  • 📡 WebSocket — stato registrazione in tempo reale
⚛️ React Frontend (Vite)

Porta: 5173 (dev) / servito da FastAPI (prod)

  • 📋 Storico chiamate
  • 🔍 Ricerca nel testo trascrizioni
  • 📁 Gestione progetti
  • 📊 Dashboard per progetto
  • 📄 Dettaglio chiamata (transcript + summary)
🪟 Electron Overlay

Finestra always-on-top, trasparente

  • 🔴 Badge "REC" + timer (stato minimale)
  • ↕️ Click per espandere (nome call, stop)
  • 📡 Connesso via WebSocket al backend
  • ⚡ Si avvia/spegne automaticamente con la registrazione
